# 时之勇者 · CHRONO REQUIEM

单文件网页卡牌游戏原型。打开 `index.html` 即可游玩（图片在 `img/`）。

- 开局选择职业：战士、刺客、法师
- 时间轴卡牌：挪动敌我行动的拍数，制造共鸣、拼刀和弹反
- 职业流派：每个职业 3 个流派，职业卡池各 18 张；从第 3 次选牌起，奖励里有一张职业牌来自你拿得最多的流派
  - 战士：铁壁（盾反）、重击（怒气爆发）、背水（残血拼刀）
  - 刺客：连击（空拍连刺）、淬毒（毒层叠加）、标记（一拍处决）
  - 法师：连锁（元素反应连环）、大咒（长吟唱）、冰封（霜冻冻碎攻击）
- 七层高塔：前五层每层从三只怪里随机遇到一只（共 15 只小怪），第 6 层黑铁骑士，塔顶永夜魔王

## 平衡模拟

`node tools/balance/run.mjs [局数] [职业]` 让一个贪心 AI 用真实规则爬塔，输出每个职业的通关率和每层平均掉血（需要 playwright）。改数值后跑一下，对照当前基线：每职业 30 局，战士约 25/30、刺客约 24/30、法师约 20/30。
