# 时之勇者 · CHRONO REQUIEM

单文件网页卡牌游戏原型。打开 `index.html` 即可游玩（图片在 `img/`，动画库 GSAP 放在 `vendor/`，直接双击打开也能用）。

界面是「命运织锦」风格：整局游戏是一幅中世纪叙事挂毯，亚麻白承载信息，靛蓝承载叙事和人物，茜草红标识危险与主要操作，暗金线表示选中与交织。设计稿在 `design/fate-tapestry/`，美术素材清单与 Codex 生成提示词在 `tools/art/tapestry_art_brief.md`。时间轴里挪动行动会抽出一根线，共鸣会打一个结，弹反会剪断敌人的布片；胜利缝入战绩，失败的画面下缘散成线，登顶时展开整幅征途。

- 开局选择职业：战士、刺客、法师
- 时间轴卡牌：挪动敌我行动的拍数，制造共鸣、拼刀和弹反
- 职业流派：每个职业 3 个流派，各有自己的核心动作；职业卡池 22~23 张。从第 3 次选牌起，奖励里有一张职业牌来自你拿得最多的流派
  - 战士：铁壁（挡：把攻击引到盾上）、重击（砸：不能挪的重击砸掉敌人的攻击）、背水（挪伤：挨的打变成打出去的伤害）
  - 刺客：连击（躲：把攻击叠在一起闪开）、淬毒（叠：毒层越叠越多）、标记（聚：把攻击汇到倍率拍上）
  - 法师：连锁（元素反应连环）、大咒（长吟唱）、冰封（推迟敌人、冻碎攻击）
- 基石牌（金框）：每个流派一张，本场战斗改写一条规则，自己不加伤害。从第 3 次选牌起出现，每次奖励最多一张
- 游戏不提示、不命名任何组合：牌面只写机制，套路留给玩家自己摸索。战斗结算只显示本场最高的一拍和那一拍用到的牌
- 七层高塔：前五层每层从三只怪里随机遇到一只（共 15 只小怪），第 6 层黑铁骑士，塔顶永夜魔王
- 岔路：每层打完后红线分岔，从两股里选一股走（第 5 层后连走两次）。路线是一串步骤（`ROAD`），节点类型登记在 `THREADS` 里，按权重抽取；节点可以往路线里再插步骤，所以加长流程只是加长队列，不需要地图坐标
  - 织坊：花金线买牌（职业牌 45、基石 80、时间牌 35）、加绣（40 起，每次 +15）、拆线（50 起，每次 +25）、缝补（25，回 15 血）
  - 纺车：回复 30% 生命，或免费给一张牌加绣
  - 金线轴：直接拿一把金线
- 金线：每场胜利 18 + 3×层数，本场最高一拍每 10 点 +1，每次弹反 +2，打赢黑铁骑士再 +30
- 绣纹：一张牌最多一种。轻线（费用 −1，怒气牌 −1 怒气）、锋线（这张牌打出的每次伤害 +4，只有造成伤害的牌能绣）、回线（打出后回到牌库顶）。绣过的牌是独立的牌 id，比如 `fireball+edge`

## 平衡模拟

`node tools/balance/run.mjs [局数] [职业]` 让一个贪心 AI 用真实规则爬塔，输出每个职业的通关率和每层平均掉血（需要 playwright）。改数值后跑一下，对照当前基线：每职业 40 局，战士约 35/40、刺客约 30/40、法师约 34/40（单次波动 ±3）。贪心 AI 不会刻意凑组合，也不走岔路、不逛织坊，所以这个数只看整体难度。
