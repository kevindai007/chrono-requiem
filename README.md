# 时之勇者 · CHRONO REQUIEM

单文件网页卡牌游戏原型。打开 `index.html` 即可游玩（图片在 `img/`）。

- 开局选择职业：战士、刺客、法师
- 时间轴卡牌：挪动敌我行动的拍数，制造共鸣、拼刀和弹反
- 职业流派：每个职业 3 个流派，各有自己的核心动作；职业卡池 22~23 张。从第 3 次选牌起，奖励里有一张职业牌来自你拿得最多的流派
  - 战士：铁壁（挡：把攻击引到盾上）、重击（砸：不能挪的重击砸掉敌人的攻击）、背水（挪伤：挨的打变成打出去的伤害）
  - 刺客：连击（躲：把攻击叠在一起闪开）、淬毒（叠：毒层越叠越多）、标记（聚：把攻击汇到倍率拍上）
  - 法师：连锁（元素反应连环）、大咒（长吟唱）、冰封（推迟敌人、冻碎攻击）
- 基石牌（金框）：每个流派一张，本场战斗改写一条规则，自己不加伤害。从第 3 次选牌起出现，每次奖励最多一张
- 游戏不提示、不命名任何组合：牌面只写机制，套路留给玩家自己摸索。战斗结算只显示本场最高的一拍和那一拍用到的牌
- 七层高塔：前五层每层从三只怪里随机遇到一只（共 15 只小怪），第 6 层黑铁骑士，塔顶永夜魔王

## 平衡模拟

`node tools/balance/run.mjs [局数] [职业]` 让一个贪心 AI 用真实规则爬塔，输出每个职业的通关率和每层平均掉血（需要 playwright）。改数值后跑一下，对照当前基线：每职业 40 局，战士约 35/40、刺客约 30/40、法师约 34/40（单次波动 ±3）。贪心 AI 不会刻意凑组合，所以这个数只看整体难度。
