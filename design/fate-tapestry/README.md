# 命运织锦 · UI 效果稿

为《时之勇者 / CHRONO REQUIEM》制作的一套桌面横屏 UI 视觉提案，覆盖职业选择、战前情报、战斗、胜利选牌、失败重试和登顶结局。效果稿用于确认视觉方向，不修改现有游戏实现。

## 视觉原则

界面是一幅持续编织的中世纪英雄挂毯。亚麻白提供清晰的信息底面，靛蓝承载叙事与角色剪影，茜草红标识危险与主要操作，暗金线表达选中、交织和关键时刻。纹理留在插画与边缘，牌面文字区保持安静。

角色、敌人、卡牌、图标遵循同一种平面纹章画法：简化侧脸、修长形体、清晰剪影、几何星结和细密植物边饰。织纹是结构与触觉线索，不能淹没文字与行动数值。

时间轴保持明确的拍数、敌方／交锋／勇者三条轨道。经线划分时间，布片表示行动，交叉与结点表达同拍关系。移动、共鸣、弹反的动效可以分别使用抽线、打结和截断折返。

职业选择使用三面纹章旗；战前情报使用异兽狩猎图与七层塔标；胜利把战斗缝入史诗并展示新布片；失败让故事下缘散线；登顶展开完整七层征途。

## 人物结构修正

战斗页中原本垂下的空手改为屈肘支撑盾牌，手掌在盾后握住盾柄；另一只手握剑。检查肩、肘、腕及遮挡关系，避免肢体与盾牌错误连接。其他人物页面已同步复查，没有发现同样的空手问题。原始 `03-battle.jpg` 保留用于版本对照，修正版下载包使用 v2。

## 校验范围

静态视觉提案通过逐图检查来确认主要界面覆盖、文字层级、构图和视觉一致性。牌名与机制参考现有 `index.html`；图中战斗状态与部分结算数据是演示内容。尚未验证动态效果、移动端适配或真实交互。
